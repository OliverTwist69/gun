# Анализ сайта FreeClaude - Freelancer Platform

## Общее описание

Это **React-приложение** для фриланс-платформы "FreelanceHub", написанное на современном стеке технологий. Приложение представляет собой полноценный фриланс-маркетплейс, где клиенты могут размещать проекты, а фрилансеры - находить работу и отправлять предложения.

## Технологический стек

### Основные технологии:
1. **React 19.2.8** - современная версия React с хуками
2. **Vite 8.3.0** - быстрый сборщик для разработки
3. **React Router DOM 7.18.4** - навигация между страницами
4. **Axios 1.20.0** - HTTP-клиент для API-запросов
5. **Oxlint 1.81.0** - линтер для кода
6. **CSS Variables** - кастомные CSS-переменные для тем

### Архитектура:
- **Single Page Application (SPA)**
- **Client-side rendering**
- **REST API** для связи с бэкендом (предположительно Node.js/Express)

## Ключевые особенности реализации

### 1. Система авторизации
- **React Context** для управления состоянием пользователя
- **JWT токены** для аутентификации
- **Локальное хранилище** для сохранения сессии
- **Защищенные маршруты** через компонент `ProtectedRoute`

### 2. Маршрутизация
- **7 основных маршрутов** + защищенные маршруты
- **Динамические маршруты** для проектов и профилей
- **Загрузка состояния** при переходе между страницами

### 3. Стилизация
- **CSS Modules** не используется, вместо этого - CSS-классы
- **CSS Variables** для поддержки темной/светлой темы
- **Адаптивный дизайн** с медиа-запросами
- **CSS Grid/Flexbox** для сложных макетов

### 4. Работа с данными
- **Axios** для API-запросов
- **React Hooks** (useState, useEffect, useContext)
- **Формы с валидацией** на клиенте
- **Фильтрация и пагинация** на странице проектов

## Основные компоненты

### AuthContext.jsx
Централизованный контекст для управления:
- Состоянием пользователя (авторизация/регистрация)
- JWT токенами
- HTTP заголовками для Axios
- Методами авторизации (login, logout, register)

### App.jsx
Корневой компонент приложения:
- Оборачивает всё в `AuthProvider` и `Router`
- Определяет все маршруты приложения
- Настраивает защищенные маршруты

### ProjectCard.jsx
Переиспользуемый компонент для отображения проектов:
- Форматирование дат
- Статус проекта с цветовой кодировкой
- Категории проектов
- Информация о клиенте
- Адаптивное отображение навыков

### Projects.jsx
Страница со списком проектов:
- Фильтрация по категориям, бюджету, поиску
- Пагинация с интеллектуальным отображением страниц
- Загрузка данных с бэкенда
- Обработка ошибок и состояния загрузки

## Бизнес-логика

### Роли пользователей:
1. **Клиент (client)** - создает проекты, просматривает предложения
2. **Фрилансер (freelancer)** - ищет проекты, отправляет предложения

### Поток работы:
1. Регистрация/вход → Выбор роли
2. Клиенты: Создание проекта → Просмотр предложений → Выбор исполнителя
3. Фрилансеры: Поиск проектов → Отправка предложений → Выполнение работы

### Функциональность:
- **Просмотр проектов** с фильтрацией
- **Отправка предложений** (presumably)
- **Система чата** между клиентами и фрилансерами
- **Личные кабинеты** для обеих ролей
- **Система рейтингов** пользователей

## API взаимодействие

Приложение предполагает бэкенд на `http://localhost:5000/api`:

```
GET    /api/projects          # Список проектов с фильтрацией
GET    /api/projects/:id      # Детали проекта
GET    /api/auth/me           # Получение текущего пользователя
POST   /api/auth/login        # Вход
POST   /api/auth/register     # Регистрация
PUT    /api/auth/profile      # Обновление профиля
```

## Стиль кодирования

### Особенности:
1. **Функциональные компоненты** с хуками (нет классовых компонентов)
2. **ES6+ синтаксис** (деструктуризация, стрелочные функции)
3. **Английские имена переменных**, но **русский интерфейс**
4. **Компонентный подход** с разделением ответственности
5. **CSS в отдельных файлах** (не CSS-in-JS)

### Качество кода:
- **Консистентное именование** (camelCase для JS, kebab-case для CSS)
- **Декларативный стиль** с React
- **Обработка ошибок** в запросах
- **Состояния загрузки** и пустые состояния
